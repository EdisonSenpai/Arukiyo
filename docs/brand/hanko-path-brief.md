# Arukiyo — Hanko Path Sakura

## Selected identity

The chosen Stage 3D identity is **Hanko Path — Sakura**.

It combines:

- a vermilion circular seal inspired by a Japanese hanko;
- a walking path that forms the letter A;
- a destination sun near the upper-right edge;
- a restrained sakura blossom near the path;
- simple geometry that remains readable as a small Android icon.
